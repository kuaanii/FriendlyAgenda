# Ampliar la agenda y ocultar navegación

El usuario conserva la página principal y pide una opción para dedicar toda la ventana a la doble página, acercándose a una agenda física. También quiere ocultar las barras de desplazamiento y poder ocultar el navbar, interpretado como el menú lateral existente.

- Ocultar las barras visibles en toda la aplicación; mantener el desplazamiento con rueda, trackpad y teclado cuando sea necesario.
- Botón para ocultar/mostrar el menú lateral desde la cabecera de la página principal.
- Botón Ampliar agenda junto a las fechas. Modo inmersivo con doble página que ocupa el ancho y el alto disponibles, sin menú, saludo ni bloques secundarios.
- Mantener las fechas, notas, herramientas y navegación al entrar/salir. Salir con botón o Escape; Escape en un diálogo cierra primero el diálogo.
- Notas largas accesibles con desplazamiento interno sin barras. Comprobar ventanas de 1440×1050 y 1000×720, ambos temas.
- Entregar versión 0.2.0 con el mismo almacenamiento compatible con la versión anterior.
